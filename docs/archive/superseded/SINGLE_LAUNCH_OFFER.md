### 為什麼選擇此要約作為首發測試？（5 行論證）：
1. **決策鏈條短**：分區總監 (DD) 擁有分區業務發展基金 (District Development Fund) 自主審批權，無須上報總公司採購部。
2. **客單價充足**：單單 HK$2,480 是個人版 ($199) 的 12.5 倍，只需簽約 2 個團隊即可直接覆蓋整月固定雲端與維護成本。
3. **自帶團隊網絡效應**：一個團隊 15 位顧問同時在展業現場使用，口碑在分區間自發傳播，形成跨團隊裂變。
4. **新人痛點最強烈**：總監最焦慮新人見客被競品打死；統一工具能將新人的產品攻防勝率拉齊至中資深水平。
5. **備用降級通道**：若總監不願公費買單，現場提供「Advisor Pro 個人早鳥價 HK$199/月」，無縫承接意向強烈的一線頂尖顧問。

## 第二部分：保本客戶數與單元經濟精算 (Break-Even Unit Economics)

### 1. 月度固定營運成本拆解 (Fixed Monthly Operating Costs - Bootstrapped)：

| 成本項目 | 預估月支出 (HKD) | 支出依據與供應商 | 屬性 |
| :--- | :--- | :--- | :--- |
| **雲端主機與全球 CDN** | HK$ 350 | AWS Amplify / Vercel Pro 靜態託管與邊緣快取 | 固定 |
| **Gemini 2.5 Flash API 基礎額度** | HK$ 800 | 每日情報抓取、差分分析與 OCR 文本備用解析 | 固定基線 |
| **頂級域名、SSL 與企業郵局** | HK$ 200 | Cloudflare Registrar + Google Workspace (1 郵箱) | 固定 |
| **客戶成功與工單支持工具** | HK$ 500 | Crisp / WhatsApp Business API 基礎月租 | 固定 |
| **緊急運維儲備金 (Buffer)** | HK$ 1,000 | 伺服器突發擴容與法規諮詢準備 | 儲備 |
| **合計固定月營運成本 ($FC$)** | **HK$ 2,850** | **保證系統穩定 7x24 運轉之最低硬性支出** | **固定總額** |

### 2. 邊際可變成本與貢獻毛利 (Marginal Economics per Team)：
* 團隊月費營收 ($P$)：HK$ 2,480
* 15 位顧問每月高頻調用 OCR/API 算力消耗 ($VC$)：約 HK$ 120 / 月
* 團隊邊際貢獻毛利 ($CM = P - VC$)：$\text{HK\$} 2,480 - \text{HK\$} 120 = \mathbf{\text{HK\$} 2,360 / \text{月}}$ (邊際毛利率 95.1%)

### 3. 保本客戶數計算 (Break-Even Customer Count)：
$$\text{Break-Even Teams} = \left\lceil \frac{\text{Fixed Costs}}{\text{Contribution Margin}} \right\rceil = \left\lceil \frac{2,850}{2,360} \right\rceil = \mathbf{2 \text{ 個分區團隊 (即 30 位顧問)}}$$

> **結論**：只要簽下 **2 個分區團隊 (District Teams)**，InsurIntel HK 即可完全擺脫虧損，達到現金流平衡！若全為個人版 ($199/月，邊際毛利 $179)，保本點為 **16 位個人付費顧問**。

## 第四部分：投資回報率 (ROI) 嚴謹重構與保守情景測算

> [!WARNING]
> **嚴禁宣傳不可驗證之「1,600% ROI」口號**。
> 任何向理財顧問或分區總監展示的收益說明，必須明確列出：保費規模、首年佣金比例 (FYC)、顧問合約分潤率、工具貢獻歸因權重，並附帶保守情景。

### 1. 基準情景測算 (Baseline Scenario · 典型中產儲蓄方案)：
* **客戶保單規模**：年繳保費 **USD 20,000** (約合 HK$ 156,000)，5 年期繳。
* **市場基準首年佣金率 (FYC Benchmark)**：26%（香港長期儲蓄分紅險常見首年佣金率區間為 22%~30%）。
* **總首年佣金池**：$\text{USD 20,000} \times 26\% = \text{USD 5,200}$ (約合 HK$ 40,560)。
* **顧問合約實收分潤比例 (Contract Payout Split)**：
  - 中資深顧問 / MDRT 合約比例約為 70%：
  - 顧問實收佣金收入 = $\text{HK\$} 40,560 \times 70\% = \mathbf{\text{HK\$} 28,392}$。
* **工具促成歸因權重 (Tool Attribution Share)**：
  - 假定此客戶原先強烈傾向對手 7% 方案，因顧問出示 InsurIntel 客觀對照撕頁與保證回本拆解，成功挽回；
  - 保守給予工具 **50% 歸因權重**（另 50% 歸功於顧問自身人際信賴與跟進努力）。
* **工具帶來的實質收益**：$\text{HK\$} 28,392 \times 50\% = \mathbf{\text{HK\$} 14,196}$。
* **單月回報率對比**：
  - 若顧問訂閱個人版 (HK$ 199 / 月)：
    $$\text{單月實測 ROI} = \frac{\text{HK\$} 14,196 - \text{HK\$} 199}{\text{HK\$} 199} \approx \mathbf{7,033\%}$$
  - 若將該單佣金摊薄至**全年軟件年費** (HK$ 199 $\times$ 12 = HK$ 2,388)：
    $$\text{全年化 ROI} = \frac{\text{HK\$} 14,196 - \text{HK\$} 2,388}{\text{HK\$} 2,388} \approx \mathbf{494.5\%}$$

---

### 2. 極度保守情景測算 (Conservative Scenario · 新人小額保單)：
* **客戶保單規模**：年繳保費僅 **USD 10,000** (約合 HK$ 78,000)，5 年期繳。
* **佣金率**：20%（較低比例產品或非旗艦方案）。
* **總佣金池**：$\text{USD 10,000} \times 20\% = \text{USD 2,000}$ (約合 HK$ 15,600)。
* **新人顧問分潤比例**：50%（入行 1 年內新人常見合約起步點）。
* **顧問實收佣金**：$\text{HK\$} 15,600 \times 50\% = \mathbf{\text{HK\$} 7,800}$。
* **工具歸因權重**：僅給予 **25% 弱歸因**（僅作為輔助確認材料）。
* **歸因實質收益**：$\text{HK\$} 7,800 \times 25\% = \mathbf{\text{HK\$} 1,950}$。
* **投資回報率**：
  $$\text{保守單月 ROI} = \frac{\text{HK\$} 1,950 - \text{HK\$} 199}{\text{HK\$} 199} \approx \mathbf{879.9\%}$$
